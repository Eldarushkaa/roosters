# Подключение Telegram

Игра работает локально без токена. Для проверки самого бота достаточно токена, username и доступа ноутбука в интернет. Для открытия игры внутри Telegram дополнительно нужен публичный HTTPS-адрес. Обычный запуск тестов или игрового HTTP-сервера не обращается к Bot API.

## Быстрая проверка бота с ноутбука

Заполнить `BOT_TOKEN` и `BOT_USERNAME` без `@` в `.env`. `WEBAPP_URL` пока можно оставить пустым или сохранить адрес-заглушку из `.env.example`. Затем запустить:

```sh
.venv/bin/python -m scripts.bot
```

Отправить своему боту `/start` в личном чате. Пока адрес игры не настроен, бот ответит, что он работает, а арена ещё не подключена. Кнопка открытия игры появится после заполнения настоящего `WEBAPP_URL` и перезапуска launcher. Для этой проверки не нужны запущенный игровой HTTP-сервер, HTTPS-туннель или webhook. Ноутбук должен оставаться включённым, а процесс — запущенным; остановка — `Ctrl+C`.

Long polling — это исходящие запросы бота к Telegram за новыми командами. Webhook — обратная схема: Telegram сам отправляет команды на публичный адрес обработчика. Это способы доставки команд боту; адрес страницы Mini App нужен отдельно при любом из них. Сейчас реализован long polling, webhook-обработчика в приложении пока нет. При переносе на сервер можно продолжить polling или добавить webhook позднее.

## 1. Бот и конфигурация

Создать бота через [@BotFather](https://t.me/BotFather), сохранить токен в локальном `.env` и вписать username без `@`:

```dotenv
APP_ENV=production
ALLOW_DEV_AUTH=false
BOT_TOKEN=123456789:your_token_here
BOT_USERNAME=your_arena_bot
WEBAPP_URL=https://arena.example.com
SECRET_KEY=replace_with_a_long_random_secret
DATABASE_PATH=data/roosters.sqlite3
HOST=127.0.0.1
PORT=8000
```

Сгенерировать секрет можно локально:

```sh
.venv/bin/python -c 'import secrets; print(secrets.token_hex(32))'
```

`.env` не входит в Git и Docker image. Bot token даёт управление ботом; не вставлять его в скриншоты, shell-команды с URL или публичные логи. Файл должен быть доступен только пользователю сервиса. Секрет должен оставаться одинаковым после перезапуска и во всех HTTP workers.

## 2. Публичный адрес

Запустить приложение на собственном сервере либо предоставить HTTPS-туннель к локальному `127.0.0.1:8000`. Туннель — отдельная программа, которая даёт ноутбуку временный публичный адрес вида `https://…` и пересылает обращения по нему в локальную игру. Браузер Telegram загружает интерфейс и вызывает игровой API по этому адресу. Поэтому работающий polling-бот сам по себе не делает локальную игру доступной в Telegram.

В `.env` указать итоговый адрес с `https://`. Telegram-кнопка не откроет `http://localhost` как полноценный публичный Mini App: с телефона это адрес самого телефона, а не ноутбука. Конкретный провайдер туннеля не требуется приложению. При изменении временного адреса обновить `WEBAPP_URL`, перезапустить launcher и заново установить меню, если оно было настроено. При публичном запуске отключить локальный тестовый вход согласно настройкам раздела 1.

Запуск HTTP в production:

```sh
.venv/bin/gunicorn --workers 2 --threads 4 --bind 127.0.0.1:8000 'roosters:create_app()'
```

Reverse proxy завершает HTTPS и пересылает запросы на этот порт. SQLite находится на локальном диске того же хоста; репликация приложения по нескольким машинам пока не поддерживается. Если использовать Docker, порт уже ограничен loopback; для прокси в другом контейнере потребуется общая Docker-сеть и обращение к `web:8000`.

## 3. Меню и команды

Команда ниже **изменяет настройки указанного бота в Telegram**: устанавливает кнопку «Арена» и команды `/start`, `/play`, `/help`. Выполнять после проверки `.env`:

```sh
.venv/bin/python -m scripts.set_menu
```

Меню также можно настроить в @BotFather. Для ссылок вида `https://t.me/<bot_username>?startapp=<referral_code>` нужно включить и настроить **Main Mini App** в @BotFather, указав тот же HTTPS-адрес. Это отдельная настройка: установка chat menu сама по себе не включает Main Mini App.

## 4. Launcher bot

Запустить отдельным процессом:

```sh
.venv/bin/python -m scripts.bot
```

Открыть личный чат своего бота, отправить `/start`, нажать «Открыть арену». Launcher использует long polling, поэтому отдельный webhook endpoint для бота не нужен. Для одного токена должен работать один polling-процесс. Если ранее у бота был webhook, удалить его отдельно в своей существующей конфигурации: эти скрипты намеренно не меняют webhook автоматически.

Игровой сервер может обслуживать меню Mini App независимо от launcher. Launcher отвечает только на команды открытия игры и не управляет валютами или матчами.

## 5. Проверка двумя аккаунтами

1. Открыть игру через Telegram с двух настоящих аккаунтов.
2. Убедиться, что имя получено из Telegram, а локальный вход отключён.
3. Проверить счётчик присутствия: два аккаунта видны как два игрока, повторная вкладка не добавляет нового.
4. Выбрать онлайн-поиск с обоих аккаунтов. До найденной пары плата не списывается.
5. Дождаться матча, нажимать на петуха, закрыть и повторно открыть приложение во время боя.
6. Проверить результат, историю, изменение валют и одинаковый итог после повторного открытия.
7. Закрыть одно приложение и дождаться истечения присутствия; счётчик должен уменьшиться.

Не оценивать работоспособность Telegram-входа по обычному браузерному открытию HTTPS-страницы: у него нет подписанного `initData`. Сервер сознательно откажет в таком входе при отключённом dev-режиме.

## Диагностика

| Симптом | Проверка |
| --- | --- |
| Бот отвечает, но кнопки арены нет | Указать настоящий публичный HTTPS-адрес в `WEBAPP_URL` и перезапустить launcher; пустое значение и шаблонный адрес включают режим проверки бота |
| «Неверный Telegram вход» | Токен на сервере должен принадлежать боту, через которого открыта игра; закрыть и заново открыть Mini App, проверить время сервера |
| Кнопка открывает старую версию | Проверить `WEBAPP_URL`, настройки Main Mini App и chat menu; перезапустить сервер после изменения `.env` |
| Launcher завершился с кодом API 401 | Проверить актуальность токена без публикации его значения |
| API 409 | Остановить второй polling-процесс либо прежний webhook |
| Нет реальных игроков | Dev-аккаунты не входят в этот счётчик; heartbeat приходит только от активного клиента |
| После рестарта пропал прогресс | Проверить постоянный `DATABASE_PATH` и Docker volume; не использовать временный контейнерный диск |
| Docker не может записать SQLite | Для bind mount проверить владельца UID/GID `10001:10001`; по умолчанию используется именованный том |

Официальные источники: [Mini Apps: запуск, initData, кнопка меню](https://core.telegram.org/bots/webapps), [Bot API: long polling](https://core.telegram.org/bots/api#getupdates), [Telegram Stars для цифровых товаров](https://core.telegram.org/bots/payments-stars). Покупки и донаты пока не реализованы; прикручивать произвольную оплату к цифровым игровым товарам внутри Telegram не следует.
